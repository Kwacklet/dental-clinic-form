# Fonts

Served from this folder so the app does not need to contact Google Fonts.

- `source-sans-3.woff2`: Source Sans 3 (body text), weights 400–700
- `source-serif-4.woff2`: Source Serif 4 (headings), weights 500–700

Both are by Adobe, released under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows free use and redistribution.
Latin character set only (includes ñ and en dashes).
